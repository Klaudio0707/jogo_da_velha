# Jogo da Velha

Este é um projeto simples de **Jogo da Velha (Tic-Tac-Toe)**, desenvolvido em **React** para praticar conceitos de componentes, estados e eventos.

cd jogo-da-velha
npm install
npm start

---

## 🧩 Funcionalidades

- 🎮 **Jogo para dois jogadores**: Alterna entre "X" e "O".
- 🏆 **Detecção de vitória ou empate**.
- 🔄 **Botão de reinício**: Comece um novo jogo a qualquer momento.
- 📜 **Histórico de jogadas**: Permite voltar a um estado anterior do jogo.
- 📱 **Responsivo**: Adaptado para dispositivos móveis.

---

## 💻 Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces.
- **TypeScript**: Adicionado para tipagem segura e manutenção do código.
- **CSS Modules**: Para estilização isolada dos componentes.
